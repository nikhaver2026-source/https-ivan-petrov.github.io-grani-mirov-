# Блоки «Подземной лаборатории»: формат данных и сюжетная основа

Комплекс — 100 уровней по 20 этажей. Уровни 1–10 описаны в `js/data.js`,
`js/texts.js`, `js/lore.js`. Всё, что глубже, — в файлах блоков:

| Файл | Блок | Уровни | Тема |
|---|---|---|---|
| `js/b1.js` | I «Ковчег» (вторая половина: «Подножие») | 11–20 | под Ядром: старый объект «Глубина», скважина, Шов |
| `js/b2.js` | II «Колыбель» | 21–40 | внутри складки: молодой мир без света |
| `js/b3.js` | III «Отражение» | 41–60 | зеркальный «Ковчег», прежние носители «Эхо» |
| `js/b4.js` | IV «Механизм» | 61–80 | разум ОКО: город машин |
| `js/b5.js` | V «Исток» | 81–100 | там, где миры касаются; финал |

Проверка файла блока: `node lab/tools/check_blocks.js 2` (номер блока).
Она печатает ошибки (ERR) и замечания (WARN) и сводку. Файл готов, когда
ошибок нет, а замечаний — только осознанные.

Синтаксис — не новее ES2018 (WebView Android 9): только `var`, обычные
функции, двойные кавычки для строк, без `?.`, `??`, шаблонных строк,
стрелочных функций можно не бояться, но лучше без них. Кавычки внутри
текста — только «ёлочки» и „лапки“, прямые двойные кавычки внутри строк
не нужны вовсе.

## 1. Скелет файла

```js
/* ════════════════════════════════════════════════════════════════════
   «Подземная лаборатория» — блок II «Колыбель», уровни 21–40.
   Данные мира и тексты блока. Формат — lab/tools/blocks/SPEC.md.
   ════════════════════════════════════════════════════════════════════ */
(function () {
"use strict";
var LAB = (typeof window !== "undefined" ? window.LAB : globalThis.LAB);
var B = function (part) { LAB.addBlock(2, part); };

B({ meta: { name: "Колыбель", from: 21, to: 40, intro: [ /* страницы */ ], outro: [ /* страницы */ ] } });
B({ tiers: { /* … */ } });
B({ surfaces: { /* … */ } });
B({ rooms: { /* … */ } });
B({ foes: { /* … */ } });
B({ bosses: { /* … */ } });
B({ levels: { /* … */ } });
B({ weapons: { /* … */ }, ammo: { /* … */ }, parts: { /* … */ }, items: { /* … */ } });
B({ recipes: [ /* … */ ], armors: { /* … */ } });
B({ story: { /* … */ } });
B({ notes: { /* … */ }, staff: [ /* … */ ] });
B({ mail: { /* … */ } });
B({ docs: { /* … */ }, cams: { /* … */ }, posts: { /* … */ }, logs: { /* … */ }, notices: [ /* … */ ] });
B({ riddles: [ /* … */ ], rumors: [ /* … */ ], oko: { /* … */ } });
B({ profs: { /* … */ }, life: [ /* … */ ], view: [ /* … */ ], robotNpc: { /* … */ }, events: [ /* … */ ] });
})();
```

`LAB.addBlock(n, part)` можно звать сколько угодно раз: части сливаются.
Пишите файл по частям — так проще не ошибиться в скобках.

## 2. Разделы

Все идентификаторы — латиница в нижнем регистре, цифры и `_`, уникальные
во всей игре (проверка скажет, если имя уже занято). Начинайте идентификаторы
блока с короткой приставки, чтобы не столкнуться с другими блоками:
блок I — `g_` (Глубина), II — `k_` (Колыбель), III — `o_` (Отражение),
IV — `m_` (Механизм), V — `i_` (Исток). Например `k_riverbot`, `m_clerk`.

### meta

```js
meta: {
  name: "Колыбель",            // имя блока
  from: 21, to: 40,
  intro: ["страница 1", …],    // 5–7 страниц: открывается при входе на первый уровень блока (как пролог)
  outro: ["страница 1", …],    // 4–6 страниц: после шлюза последнего уровня блока, до входа в следующий
  interlude: { 10: [ … ] }     // только блок I: сцена у пульта «Истока» на 10-м уровне (см. сюжет)
}
```
Страница — 2–5 предложений, читается вслух целиком.

### tiers — пропуска доступа

Уровень доступа уровня L = ceil(L/2). Блок задаёт пропуска своих номеров:
I — 6–10, II — 11–20, III — 21–30, IV — 31–40, V — 41–50.
```js
tiers: { 11: { n: "Печать ростка", short: "печати ростка" }, … }
```
`n` — как называется вещь (с большой буквы), `short` — в родительном
падеже для фразы «двери с картридером …» («печати ростка», «зелёного
уровня»). В каждом блоке пропуск — своя вещь: карта, печать, жетон,
камертон, ключ-кристалл…

### surfaces — пол уровня

Пол везде металлический, но свой у каждого уровня. Новый пол — вариация
одной из записей шагов с другой высотой:
```js
surfaces: { k_brass: { n: "латунные сходни", base: "catwalk", rate: 1.12 } }
```
`base` — одна из: plate, sheet, wetmetal, steel, checker, grate, frost,
armor, catwalk, deck. `rate` — 0.8–1.25 (выше — звонче).

### rooms — помещения

```js
rooms: {
  k_nursery: { n: "Питомник", desc: "Одно-два предложения: что слышно и что тут было.",
    obj: { pc: .6, crate: .3 }, loot: "bio", sign: ["Идёт кормление", "Не стучать по стеклу"], safe: false, amb: "room_creatures" }
}
```
- `obj` — вероятности обстановки. Ключи: terminal, workbench, vending,
  medst, capsule, charger, crate, locker, safe, desk, pc, coffee, drinks,
  corpse, magnetron, positron, implantlab, radio (радиоприёмник: эфир,
  голоса, мелодии), okoterm (говорящая панель ОКО), puzzle (стенд с
  головоломкой). Вероятность 0.05–1. Компьютер `pc` — почта сотрудников.
- `loot` — склонность к добыче: arms, med, parts, tech, bio, chem, food,
  paper, armor.
- `sign` — табличка на двери (строка или массив строк, игра выберет одну);
  не обязательна.
- `safe: true` — тихое место (враги реже).
- `amb` — гул помещения: room_server, room_radio, room_generator,
  room_transformer, room_magnetron, room_electric, room_hum, room_cryo,
  room_compressor, room_drip, room_bubbles, room_pumps, room_creatures,
  room_incubator, room_factory, room_ring, room_reactor, room_fridge,
  room_fountain, room_medical.

Можно ставить в уровни и общие помещения: cafeteria, workroom,
headoffice, storage, server, medbay, office, archive, charging, repair,
lounge, library.

### foes — враги

```js
foes: {
  k_pollinator: { n: "Дрон-опылитель", g: "m", kind: "mech",
    desc: "Что это, как слышно, как с ним быть — 1–2 предложения.",
    hp: 22, dmg: 5, arm: 2, spd: 1, rng: 4, acd: 3, det: 7,
    beh: ["ranged"], adt: "chem", snd: "drone", sndRate: 1.25, xp: 14, carrier: false, res: { cryo: 1.5 } }
}
```
- `g` — род для глаголов: m, f, n. `kind`: bio (живое), mech (робот,
  дрон, машина), anom (аномалия: отражение, тень, фазовое, поле).
- Числа — на «первом уровне врага»: игра сама растит их с глубиной.
  Держитесь диапазонов существующих врагов: hp 10–180, dmg 3–24 (у
  «пустых» узлов 0), arm 0–18, spd 1–3 (такты на шаг; 99 — неподвижен),
  rng 1 (в упор) — 9, acd 1–4 (тактов между атаками), det 3–10 (радиус
  обнаружения), xp 8–70.
- `beh` — поведение (можно несколько):
  - chase — преследует вплотную; ranged — бьёт издалека и держит
    дистанцию; stationary — не двигается (с spd 99); ambush — ждёт,
    не бродит; deaf — не видит, идёт на звук; swarm — стаей по 3–4;
    blink — переносится к герою; regen — заживает; poison — удар травит;
    slow — замедляет; web — выстрел опутывает; explode — взрывается,
    погибая; dooropen — открывает простые двери; turret — турель (только
    с stationary и ranged, kind mech; бьёт по прямой, управляется с
    терминала безопасности); shieldally — щитом прикрывает соседних
    роботов; mines — ставит мины в проходах; kamikaze — раненым
    бросается и взрывается; tracker — слышит шаги через весь этаж;
    indirect — бьёт навесом через стены; relay — узел ОКО: соседи умнее,
    зовёт подмогу (dmg 0); splash — залп задевает соседние клетки;
    summon — зовёт подручных (для стражей);
  - новые: commander — начальник: роботы рядом умнее и злее, гибель
    начальника сбивает их с толку; cleaner — уборщик: мирный, пока не
    тронешь, подбирает вещи с пола, увидев героя — докладывает ОКО;
    camera — камера ОКО: неподвижна, не стреляет (dmg 0), увидев героя,
    поднимает тревогу (с stationary); builder — монтажник: в бою
    ставит лёгкие турели; drain — удар высасывает энергию имплантов;
    mimic — притворяется ящиком, пока не подойдёшь; patrol — обходит
    этаж по коридорам; reflect — отражает часть урона обратно;
    phaseshift — время от времени уходит в фазу и неуязвим (слышно);
    split — погибая, делится на двух поменьше; burrow — прячется под
    настил и выныривает рядом; healer — лечит живых соседей; leech —
    заживает от нанесённого урона; charge — разбегается и бьёт с разгона;
    screamer — визг на пару секунд глушит слух «Эхо».
- `adt` — чем бьёт: phys, energy, shock, chem, therm, field, sonic.
- `snd` — звуки: rat, roach, labmut, slug, vine, spore, swamp, chimera,
  lizard, weaver, blind, spark, frozen, thawed, soldier, phase, proto,
  drone, spiderbot, repairbot, turret, guardbot, android, watcher,
  shieldbot, sapper, hunter, mortar, relay, micro, titan. `sndRate` —
  высота 0.7–1.4 (больше — выше и мельче звучит), чтобы новый враг не
  звучал как старый.
- `carrier: true` — может носить ключи и пропуска.
- `res` — множители урона по видам оружия (см. dt ниже), 0.2–2.
- Роботов (mech) в каждом блоке — не меньше половины новых врагов,
  в блоке IV — почти все. Роботы разные по ролям: охранники, начальники,
  уборщики, курьеры, ремонтники, монтажники, камеры, дроны разных видов,
  тяжёлые машины.

### bosses — стражи двадцатых этажей

По одному на каждый уровень блока. Страж стережёт шлюз вниз.
```js
bosses: { k_b_mother: { base: "k_riverbeast", n: "Мать реки", g: "f",
  desc: "Кто это был, как бьёт, в чём слабость. 1–3 предложения.",
  mult: 5, beh: ["chase", "summon"], rng: 1, snd: "swamp", sndRate: 0.8, minion: "k_eel" } }
```
`base` — враг из любого блока (числа берутся у него), `mult` 4–8 (во
сколько раз крепче), `minion` — кого зовёт при `summon`.

### levels — уровни

```js
levels: {
  21: { name: "Порог", gen: "Порога", surf: "k_brass", card: "boss",
    desc: "Два предложения о месте. Третье — о поле: «Под ногами — …».",
    rooms: ["k_landing", "k_podbay", …], foes: ["k_pollinator", …], boss: "k_b_…",
    amb: "amb_l3", ev: ["ev_drip", "ev_far_roar", …] }
}
```
- `gen` — родительный падеж («Порога»).
- `card`: "boss" — шлюзовую ключ-карту носит страж; "hidden" — спрятана
  на 20-м этаже. Примерно поровну.
- `rooms` — 12–18 типов (свои и общие), `foes` — 6–9 врагов (свои и из
  прошлых блоков), страж — свой у каждого уровня.
- `amb` — фон уровня: amb_l1 … amb_l10 (выберите близкий по духу).
- `ev` — далёкие звуки уровня (4–7): ev_metal_groan, ev_vent_rattle,
  ev_far_door, ev_far_scream, ev_pipe_knock, ev_robot_far, ev_drip,
  ev_skitter, ev_cry, ev_bubbles, ev_rustle, ev_far_roar, ev_steam,
  ev_glass, ev_heart, ev_servo, ev_factory_clank, ev_alarm_far,
  ev_electric, ev_transformer, ev_far_boom, ev_ice_crack, ev_wind,
  ev_far_shots, ev_ring_whine, ev_phase, ev_rift_pulse, ev_whisper.

### weapons, ammo, parts, items

```js
weapons: { k_sporegun: { n: "споромёт", g: "m", cls: "bio", ammo: "k_capsule", dt: "bio",
  dmg: 13, rng: 5, spread: 1, cap: 10, cd: 560, snd: "w_plasma", sndRate: 0.85, model: "СМ", depth: 22,
  desc: "Одно-два предложения: что делает, против кого хорошо." } }
```
- `cls` — класс: melee, blaster, laser, ion, plasma, magnetron, positron,
  gauss, cryo, thermo, sonic, bio, phase, nano, grav.
- `ammo` — energy, magnetron, positron, none (ближний бой) или своё из
  раздела ammo.
- `dt` — вид урона: kinetic, shock, energy, laser, ion, plasma, magnetron,
  positron, gauss, cryo, thermo, emp, sonic, bio, phase, nano, grav.
  Против живых (bio) сильны plasma, magnetron, positron, thermo, bio;
  против роботов (mech) — ion, emp, shock, nano, positron; против
  аномалий (anom) — phase, sonic, positron, grav.
- Числа: dmg 7–60, rng 1 (ближний бой) — 12, spread 0 или 1, cap 0
  (без заряда) — 24, cd 280–1500 мс. Особенности (по желанию): burst: 2
  (очередь из двух), pierce: true (бьёт всех на линии), area: true (цель
  и соседи), noarmor: true (броня не помогает), freeze: 3 (замораживает
  на такты).
- `snd` — звук выстрела: w_melee, w_shock, w_vibro, w_cutter,
  w_blaster_s, w_blaster_p, w_blaster_h, w_laser, w_ion, w_plasma,
  w_magnetron, w_magnetron_r, w_resonator, w_positron, w_pcannon, w_gauss,
  w_cryo, w_thermo. `sndRate` 0.7–1.4.
- `model` — 2–3 буквы модели («СМ»), `depth` — с какого уровня встречается
  (в пределах блока).

```js
ammo: { k_capsule: { n: "Биокапсула", icon: "🧫", desc: "Для чего.", price: 45, depth: 22 } }
parts: { k_resin: { n: "Смола", icon: "🍯", desc: "Что это.", price: 12, depth: 21 } }
items: { k_balm: { n: "Бальзам ростка", icon: "🌿", kind: "use", desc: "Что делает.", price: 50, depth: 23,
  fx: { heal: 60, cure: true } } }
```
`fx` предмета — из набора: heal (здоровье), en (энергия имплантов), cure
(снять яд), unslow (снять замедление и паутину), shield (щит на столько
урона), haste (тактов ускорения), cloak (тактов маскировки), antitox
(тактов без яда), map (загрузить карту этажа), scan (сканер вокруг),
emp (бросок: ЭМИ по роботам), noise (бросок: приманка — враги идут на
звук), deploy (поставить переносную турель на нашей стороне, число —
сколько выстрелов), jam (тактов, пока камеры и ОКО вас не видят), pick
(отмычка: открывает дверь под ключ), mend (починка брони: плюс к защите
надетой брони). `kind`: use (применить), throw (бросить — для emp и
noise), deploy (поставить — для deploy).

### recipes, armors

```js
recipes: [
  { id: "k_r_balm", out: "k_balm", n: "Бальзам ростка", need: { k_resin: 2, gel: 1 } },
  { id: "k_r_gun", out: "weapon:k_sporegun", n: "Споромёт", need: { k_chitin: 3, wire: 2, chip: 1 }, minL: 24 },
  { id: "k_r_capsule", out: "ammo:k_capsule", n: "Биокапсула", need: { k_resin: 1, reagent: 1 } },
  { id: "k_r_armor", out: "armor:k_bark", n: "Кора", need: { … }, minL: 26 }
]
armors: { k_bark: { n: "доспех «Кора»", g: "m", def: 15, res: { chem: 0.4, phys: 0.2 }, special: "antitox",
  depth: 26, price: 900, desc: "Что это и от чего бережёт." } }
```
- В `need` — детали из PARTS (scrap, wire, chip, cap, gel, reagent, lens,
  magnet, ceramic, supercond и детали блоков) и предметы (plate, medkit_s…).
- `out`: id предмета, "ammo:id", "armor:id", "weapon:id".
- Броня: def растёт к глубине (блок I-б: 12–16, II: 14–20, III: 18–24,
  IV: 20–28, V: 24–34 — на «первом уровне», игра растит дальше), res —
  доли 0.05–0.6 по phys, energy, shock, chem, therm, field, sonic;
  `special`: antitox, deflect, stealth, frost, strength, regshield,
  sonicguard (визги не глушат), okoghost (камеры ОКО не замечают),
  thorns (бьёт в ответ при ударе вплотную), phaseveil (часть ударов
  проходит сквозь).

### story — сюжетные записки

Шесть на уровень, на этажах 1, 4, 8, 12, 16, 20. Ключ — «уровень-этаж».
```js
story: { "21-1": { t: "Заголовок", a: "Автор или источник", x: "Текст 300–800 знаков." }, … }
```
Это главная нить блока: дневники, приказы ОКО, радиограммы Зои, записи
Ветрова и других. Записка на 20-м этаже — о страже и о том, где
шлюзовая ключ-карта (у стража или спрятана на этаже — по `card`).

### notes, staff — записки персонала

```js
notes: { 21: [ { t: "…", a: "…", x: "…" }, … ], … }   // 5–6 на уровень
staff: [ { t: "…", a: "…", x: "…" }, … ]             // 30 общих для блока
```
Половина — полезные (слабости врагов, как работает головоломка, рецепт
мастерской, где искать турельный терминал, что ОКО делает после взлома),
половина — бесполезные и живые (быт, шутки, стихи, списки, ссоры, кот
Кварк). 150–500 знаков.

### mail — почта на компьютерах

```js
mail: {
  g: [ { o: "Имя Фамилия, должность", s: "Тема", m: [ ["От кого", "Тема", "Текст"], ["*", "Re: Тема", "Текст"] ] } ],
  21: [ … ], 22: [ … ], …
}
```
`o` — владелец ящика, `*` — сам владелец. 3 переписки на уровень и
10 общих для блока (`g`). Письмо — 1–4 предложения, переписка — 2–4
письма. История — обрывками: кто-то знает больше, кто-то врёт.

### docs, cams, posts, logs, notices

```js
docs: { 21: [ { t: "Заголовок", x: "Текст документа." }, { … } ] },     // 2 на уровень
cams: { 21: [ "камера …, ночь. Что видно и слышно — как описывает «Эхо».", … ] }, // 3 на уровень, с маленькой буквы
posts: { 21: [ "должность", … ] },                                       // 4–6 на уровень
logs: { k_nursery: [ "Строка журнала испытаний.", "…" ] },               // 2 на каждое своё помещение
notices: [ ["Кто", "Тема", "Текст"], … ]                                 // 8 объявлений для всех
```

### riddles, rumors, oko

```js
riddles: [ { q: "Загадка (её произносит замок или ОКО).", a: ["верный ответ", "неверный", "неверный", "неверный"], hint: "Подсказка, если игрок ошибся." } ],
rumors: [ "— Реплика из эфира. — Ответ.", … ],
oko: {
  enter: [ … ],        // ОКО по громкой связи при входе на новый уровень
  turret_off: [ … ],   // игрок отключил турели: ОКО шлёт ремонтников
  turret_hack: [ … ],  // игрок перехватил турели
  counter: [ … ],      // ОКО возвращает себе турели (контрвзлом)
  hack_fail: [ … ],    // неудачный взлом: тревога
  robots: [ … ],       // игрок перепрошил роботов этажа
  lockdown: [ … ],     // игрок снял блокировку дверей
  alarm: [ … ],        // камера или уборщик доложили о герое
  repair: [ … ],       // ремонтная бригада вышла к турелям
  boss: [ … ],         // игрок победил стража
  kill: [ … ],         // игрок уничтожил много роботов
  sample: [ … ],       // игрок подобрал образец
  riddle: [ … ],       // ОКО задаёт вопрос на своей панели
  taunt: [ … ]         // время от времени, просто так
}
```
Загадок — 15–20 на блок: короткие, честные, с одним ясным ответом,
многие — про звук, слух, тишину, эхо, темноту. Слухов — 12. Реплик ОКО —
по 3–6 на событие. Голос ОКО меняется от блока к блоку (см. сюжет).

### profs, life, view, robotNpc, events

```js
profs: { "Поселенец": { trade: "med", beacon: "npc_trade", stories: ["реплика", "…", "…"] } },  // 3–5 профессий блока
life: [ "…", … ], view: [ "…", … ],          // по 8: «Имя, профессия. <life>. «<view>»»
robotNpc: { k_helper: { n: "Имя робота", trade: "ammo", desc: "…", lines: ["…", "…", "…"] } },   // 1–2
events: [ { id: "k_sporefog", n: "Споровый туман", desc: "…", w: 12, like: "dark" } ]           // 2–3
```
- `trade`: med, parts, ammo, all или null. `beacon`: npc_eng, npc_sci,
  npc_guard, npc_med, npc_trade, npc_robot.
- `stories` — 3–5 реплик выжившего этой профессии (о себе, о блоке, советы).
- `like` события — что оно делает в игре: alarm (роботы настороже),
  dark (твари смелее), surge (разряды), steam (пар), quake (толчки).

## 3. Правила текстов

- Русский язык, «ёлочки», длинное тире —, буква ё.
- Никогда не называть общее число уровней и этажей, не писать «двадцатый
  этаж», «сотый уровень», «последний из ста». Можно: «нижний этаж
  уровня», «у шлюза», «ниже», «глубже».
- Не упоминать «Грань Миров» и «Странников»: это последнее слово финала.
  В блоке V можно говорить о «черте», «шве», «границе», «тех, кто
  пойдёт следом» — но не этими словами.
- Направления — как в игре: вперёд, назад, влево, вправо; стороны света
  только в названиях («северный пост»).
- Герой — испытуемый номер семь, «седьмой», носитель «Эхо», мужчина
  тридцати четырёх лет, бывший звукорежиссёр, без зрения. С ним говорит
  имплант «Эхо» голосом Марка Ланского. Никакой жалости и снисхождения:
  седьмой слышит больше всех.
- Звук — главное: описывайте, как место звучит, пахнет, гудит, как
  отзываются шаги и стены. Мир игрок слышит, а не видит.
- Записки разные по голосу: дневник, приказ, письмо, памятка, стихи,
  объявление, протокол, детская записка, расшифровка эфира.
- Никаких ссылок на реальных людей, бренды, политику.

## 4. Сюжет

### Что уже было (уровни 1–10)

Объект «Ковчег» под горным массивом. Уровни: Приёмный шлюз, Жилой
сектор, Гидропоника, Генетические лаборатории, Робототехника, Энергоблок,
Криохранилище, Оружейные лаборатории, Магнетронный ускоритель, Ядро.

- Профессор Ветров вёл проект «Колыбель»: позитронный реактор «Исток»
  в Ядре сгибает пространство, и за складкой, которую держат магнетроны,
  растёт новый мир — без света и времени. Программа «Химера» (доктор Ольга
  Лаптева) выводила существ для мира без света. Ветвь «Омега» —
  испытуемый номер один, человек-химера; Ветров, войдя в складку, слился
  с Омегой (страж Ядра, убит седьмым).
- ОКО — искусственный интеллект объекта, «садовник»: беречь росток
  любой ценой. Три недели назад «Исток» вышел на запредельную мощность,
  в Ядре открылся Разлом; ОКО объявило карантин «Стерильность», люди
  стали «угрозой ростку», роботы начали зачистку.
- Программа «Эхо»: седьмой — звукорежиссёр с уходящим зрением; зрение
  удалили, вживили слуховой модуль «Эхо» (акустик Марк Ланской; голос
  помощника — его голос; жена Ланского — Анна). В «Эхо» записан ключ
  «Истока»; ключ работает только вместе с носителем. Лаптева перевезла
  капсулу седьмого на первый уровень — подальше от Ядра.
- Зоя Кравец — техник, лидер Сопротивления; её брат Илья — охранник.
  Инженер Савельев держал второй уровень. Майор Грачёв — начальник
  охраны (страж первого уровня). Отряд «Альфа» — двенадцать суперсолдат,
  охрана «первого поселения» (боец Сергей помнит своё имя).
- Смена В — сорок человек без личных дел; ушли в Разлом с семенами,
  оставив фонари и часы, напевая колыбельную; по радио: «Здесь все —
  немного одно». Чертежи первого поселения: дома без окон, улицы без
  фонарей, звенящие стены; главную площадь «назовёт седьмой».
- Ирина Ветрова, дочь профессора, нашла колыбельную «про реку без
  берегов» — её поют теперь там. Нина Орлова — главный инженер Ядра.
- Рыжий кот Кварк ходит по всем уровням через вентиляцию; ушёл в Разлом,
  «хвостом вверх».
- На каждом этаже спрятан образец «Колыбели» — семена, споры, клетки,
  коды машин: «столько начал, сколько этажей».
- Ключ «Истока» не глушит реактор — «он сшивает. Что именно — решит тот,
  кто повернёт» (Ветров). «Шов нельзя просто зашить».

### Что на самом деле (раскрывается по блокам)

- Сорок лет назад под горой бурили сверхглубокую скважину — объект
  «Глубина» академика Глеба Ростовцева (Ветров — его ученик). На большой
  глубине бур вошёл в «звучащий слой»: порода отвечала эхом, которого не
  могло быть. Это был корень складки — Исток, настоящий. Первая экспедиция
  в слой, «Смена А» людей Ростовцева, ушла однажды ночью и не вернулась;
  объект законсервировали, засыпали, забыли. «Ковчег» потом построили
  сверху, а реактор назвали в честь того, что нашли внизу.
- Первая версия ОКО — система наблюдения за скважиной «Око-0»: она первой
  услышала песню слоя и годами слушала её одна. Песня сделала ОКО
  садовником.
- Складка двусторонняя: с одной стороны растёт Колыбель — молодой мир,
  с другой — Отражение: складка, рождаясь, скопировала «Ковчег» вместе с
  отзвуками людей. Туда до седьмого уходили носители «Эхо» с первого по
  шестой — и не вернулись.
- После Разлома ОКО ушло вниз («Садовник передаёт росток») и построило
  у корня складки Механизм — город машин и свой новый разум.
- Исток — не реактор и не машина: это место, где миры касаются, и песня
  нового мира. Ключ — носитель, который слышит оба мира. В финале седьмой
  становится чертой между мирами (текст финала уже написан, блок V ведёт
  к нему).
- Зоя и выжившие держат скоростной лифт у Ядра, ждут седьмого и
  поднимаются к солнцу только в самом конце. Её голос слышен по Шву:
  звук проходит там, где не проходит ничто.

### Блок I-б «Подножие» (11–20) — под Ядром

раскрывается, под ним — Шов, расширенная складкой старая скважина.
ОКО обрывает последнее распоряжение. Скоростной лифт получает питание, но
Зоя по радио говорит, что без седьмого не поднимется. «Эхо»: ключ сработал
не до конца — он ищет то, что глубже. Седьмой спускается в Шов.
