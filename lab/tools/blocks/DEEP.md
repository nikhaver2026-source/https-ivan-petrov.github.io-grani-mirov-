помещениях, врагах, стражах, оружии, предметах, броне, текстах, — в силе и
здесь. Ниже — чем глубокий блок отличается.

## 0. Главное отличие: уровней сотни тысяч

Писать каждый уровень нельзя. Глубокий блок пишется **секторами**: блок
делится на сорок полос уровней, в каждой полосе — один сектор блока
(первая полоса — первый сектор, последняя — сектор с `end: true`, между
ними секторы вперемешку). Уровень называется по сектору: «Огневой
полигон, ярус 3». Враги, помещения и стражи уровня — из его сектора.

Сюжетные записки — **вехи**: первые четыре уровня блока, два последних и
первый уровень каждого сектора, когда сектор встретился впервые. Остальные
записки, почта, документы — пулы на весь блок.

Числа (здоровье, урон, цены) движок растит сам по приведённой глубине:
каждый глубокий блок прибавляет к ней столько же, сколько прежний блок в
двадцать уровней. Пишите числа врагов и оружия, как в блоке V (на «первом
уровне врага»), — движок поднимет.

Срезы (короткие пути вниз через тайные комнаты и подсобки) движок ставит
сам; блок задаёт только их названия и звучание (раздел `deep.cuts`).

## 1. Скелет файла

```js
/* ════════════════════════════════════════════════════════════════════
   «Подземная лаборатория» — блок VI «Полигон», уровни 101–300.
   Данные и тексты глубокого блока. Формат — lab/tools/blocks/DEEP.md.
   Синтаксис — не новее ES2017.
   ════════════════════════════════════════════════════════════════════ */
(function () {
"use strict";
var LAB = (typeof window !== "undefined" ? window.LAB : globalThis.LAB);
var D = function (part) { LAB.addDeep(6, part); };

D({ meta: { name: "Полигон", kind: "испытательный комплекс", intro: [ … ], outro: [ … ] } });
D({ deep: { … } });
D({ sectors: [ … ] });
D({ rooms: { … } });
D({ foes: { … }, bosses: { … } });
D({ weapons: { … }, ammo: { … }, parts: { … }, items: { … }, recipes: [ … ], armors: { … } });
D({ milestones: { … }, sectorStory: { … } });
D({ staff: [ … ], mail: [ … ], docs: [ … ], cams: [ … ], posts: [ … ], logs: { … }, notices: [ … ] });
D({ riddles: [ … ], rumors: [ … ], oko: { … } });
D({ profs: { … }, life: [ … ], view: [ … ], robotNpc: { … }, events: [ … ] });
})();
```

`LAB.addDeep(n, part)` можно звать сколько угодно раз: части сливаются.
Пишите по частям.

Синтаксис — не новее ES2017: `var`, обычные функции, двойные кавычки для
строк. Внутри текста — только «ёлочки» и „лапки“, буква ё, длинное тире —.

## 2. Разделы

Все идентификаторы — латиница в нижнем регистре, цифры и `_`, с приставкой
блока (`v6_`, `v7_` …), уникальные во всей игре.

### meta

```js
meta: {
  name: "Полигон",                 // имя блока: «Блок шестой. Полигон»
  kind: "испытательный комплекс",  // что это за комплекс — одно-три слова
  intro: ["страница", …],          // 5–7 страниц: при входе в блок
  outro: ["страница", …]           // 4–6 страниц: после последнего уровня блока
}
```
Страница — 2–5 предложений, читается вслух целиком. `from` и `to` не
пишите — их знает движок.

### deep — устройство блока

```js
deep: {
  era: "P",                    // уклад кабинетов и обстановки: всегда "P" (см. сюжет)
  surf: "tile",                // пол помещений по умолчанию
  roomSurf: {                  // пол по роду помещения (род — как у охраны: см. ниже)
    office: "carpet", lab: "tile", med: "tile", living: "carpet", store: "concrete",
    tech: "concrete", arms: "rubber", power: "concrete", server: "tile", sec: "rubber", any: "tile"
  },
  pass: { n: "Жетон Полигона", short: "жетона Полигона" },  // пропуск доступа блока (+ номер ступени)
  corr: { gallery: "Смотровая галерея", passage: "Переход испытателей" },  // как зовутся широкие и узкие коридоры
  stairs: { n: "Аварийный трап", desc: "Одно предложение: как звучит лестница блока." },
  cuts: [                      // 3–5 видов срезов блока (короткие пути вниз)
    { id: "v6_cut_drop", n: "Аварийный спуск испытателей", need: "power",
      desc: "Что это и как звучит — 1–2 предложения.", ride: "Как идёт спуск — 1–2 предложения." }
  ],
  ai: { n: "Экзаменатор", desc: "Кто говорит по громкой связи в этом блоке (облик Переклички) — 1–2 предложения." },
  rent: [ … ],                 // только блок VI: прокатный комплект (см. механики)
  norms: [ … ],                // 4–6 норм (см. механики)
  trials: [ … ],               // испытания: блок VI — 8–10, прочие — 3–5
  market: { n: "…", lines: ["…", "…", "…"] },  // теневой торговец «вне надзора»
  memories: [ { t: "…", x: "…" }, … ],         // 6–10 вспышек памяти (мнемоник)
  cards: { v6_xxx: "Карточка твари голосом Переклички: ранг, повадка, слабость, чем бить.", … } // на каждого врага блока
}
```
- Полы (`surf`, `roomSurf`, `fl` помещения): `concrete`, `wood`, `carpet`
  (ковролин), `grass` (газон, мягкая земля), `sand` (песок), `stone`
  (каменная плитка), `tile` (кафель), `rubber` (резиновые маты), `metal`
  (металл уровня) или любой пол из `surfaces` блока. Коридоры в глубоких
  блоках — бетонные все, это делает движок.
- Род помещения для `roomSurf`: `arms` (оружейные), `sec` (охрана), `server`,
  `vault` (хранилища), `power` (энергия), `lab`, `med`, `living` (жильё),
  `store` (склады), `office` (кабинеты, деревянные наверху), `tech`
  (технические, бетонные наверху), `any` — прочие.
- `need` у среза: `power` (запустить лебёдку — нужна энергобатарея), `puzzle`
  (пульт — головоломка), `crank` (ручная лебёдка: долго и шумно, Перекличка
  слышит), `harness` (вертикальный ствол — нужна страховочная сбруя: предмет
  блока VI `v6_harness`, движок даёт его в продаже), `code` (код из записки
  этого этажа), `none` (открыт).

### sectors — секторы блока

```js
sectors: [
  { id: "fire", name: "Огневой полигон", gen: "Огневого полигона",
    desc: "Два предложения о месте. Третье — о поле: «Под ногами — …».",
    rooms: ["v6_range", "v6_bunker", …],     // 12–18 типов: свои и общие (см. SPEC.md)
    foes: ["v6_target", …],                   // 6–9: свои, можно 1–2 из прошлых блоков
    bosses: ["v6_b_marshal", "v6_b_…"],       // 2–3 стража сектора (одного выбирает уровень)
    amb: "amb_l8", ev: ["ev_far_shots", …],   // фон и далёкие звуки (списки — в SPEC.md)
    surf: "sand",                              // пол помещений сектора по умолчанию (по желанию)
    card: "boss" },                            // ключ-карта 20-го этажа: у стража ("boss") или спрятана ("hidden");
                                               // нет — по жребию; записка 20-го этажа должна говорить то же
  …,
  { id: "heart", …, end: true }               // сердце блока — последняя полоса
]
```
8–12 секторов. Первый в списке — вход в блок, последний с `end: true` —
сердце блока у его дна. Каждое помещение блока должно стоять хотя бы в
одном секторе; каждый враг — хотя бы в одном секторе.

### rooms — помещения

Как в SPEC.md, и ещё:
- `fl` — пол помещения (см. полы). Пусть полы помещений блока будут
  разными: в одном комплексе — кафель лабораторий, ковролин кабинетов,
  резина спортзалов, песок арен, камень старых выработок.
- `dark: true` — помещение «вне надзора» (сумрак): камер нет, бывает теневой
  торговец, засады чаще. 2–4 таких на блок.
- `rank: 2` — дверь «только с допуска» (статус Переклички, см. механики):
  1–3 таких на блок.
- `trial: true` — испытательная камера (в ней стенд испытания). В блоке
  VI — 5–8 таких, в прочих — 1–3.
- 24–36 своих помещений на блок.

### foes, bosses — как в SPEC.md

- Роботы (`kind: "mech"`) — не меньше половины новых врагов. У машин —
  роли: охранники, начальники (commander), уборщики (cleaner), курьеры,
  ремонтники, монтажники (builder), камеры (camera), дроны, тяжёлые машины,
  турели (turret), кордоны.
- Твари (`kind: "bio"`) — с разумом, рангом, семейством, как в
  `js/mutants.js`: `mind` 0 — неразумные (инстинкт), 1 — полуразумные
  (стаи, хитрость), 2 — разумные (двери, фланги, отряды, вожак), 3 —
  сверхразумные (улей, провидцы); `rank`: low, mid, high, apex; `fam` —
  семейство для бестиария; у разумных — `caste` (worker, soldier, hunter,
  spitter, guard, priest, seer, leader, queen, drone, trapper). В каждом
  блоке — твари всех четырёх ступеней разума.
- Новые повадки (`beh`) можно брать из SPEC.md и `js/mutants.js` (flee,
  howl, bomber, trapper, feeder, rad, psi, corrode, silent, adapt, lure,
  marker). Своих новых слов не придумывайте — движок их не знает.
- 18–26 врагов на блок, 16–24 стража (по 2–3 на сектор). `base` стража —
  враг этого блока.
- Числа — как в блоке V: hp 10–180, dmg 3–24, arm 0–18.

### weapons, ammo, parts, items, recipes, armors — как в SPEC.md

- `depth` у оружия, патронов, деталей, предметов — **доля блока**: `at`
  от 0 до 1 вместо номера уровня (`at: 0.3` — с трети блока). Нет `at` —
  с начала блока.
- Оружие по мотивам книг и своего комплекса (иглострелы, гвоздомёты, пневмо,
  звуковые, гравитационные, резаки, каталитические, медицинские…): 5–8.
  `cls` и `dt` — из списков SPEC.md. Новое поле `rank: 3` — «оружие по
  допуску»: стреляет, только если статус Переклички не ниже (1–2 такого
  оружия на блок, сильного).
- Броня: 4–6, среди них экспериментальная; `special` — из списка SPEC.md.
  Новая особенность `harness` (страховочная сбруя: срезы с `need: "harness"`
  без предмета) — по желанию одна броня в блоках VI–VIII.
- Предметы: 5–8, `fx` — из SPEC.md и новые: `regen: [мин, ед.]` —
  отложенная регенерация (через столько минут — столько здоровья),
  `stitch: true` — закрыть рану (кровотечение), `memory: true` — мнемоник
  (вспышка памяти из `deep.memories`, герой на время беззащитен),
  `antimut: true` — антидот капсулы мутагена (блок VIII).
- Детали: 3–5, у каждой можно `from`: `"mech"` (снимают с машин), `"bio"` (с тварей)
  или `"anom"` (вещество аномалий) — с павших врагов падают только детали их
  природы; нет `from` — движок угадает по названию. Рецепты: 10–14 (детали из
  PARTS и своего блока), у рецепта тоже можно `at` — с какой доли блока его
  можно собрать.

### milestones, sectorStory — сюжетные записки

```js
milestones: {
  "first+0-1": { t: "Заголовок", a: "Автор", x: "300–800 знаков." },  // первый уровень блока, этаж 1
  "first+0-4": …, "first+0-8": …, "first+0-12": …, "first+0-16": …, "first+0-20": …,
  "first+1-1": …, …                         // второй, третий, четвёртый уровни блока (first+1 … first+3)
  "last-1-1": …, …, "last-0-20": …          // два последних уровня блока (last-1, last-0)
},
sectorStory: { fire: { 1: {…}, 8: {…}, 20: {…} }, … }  // первый уровень каждого сектора, этажи 1, 8, 20
```
Этажи — 1, 4, 8, 12, 16, 20 (как в SPEC.md). Всего на блок: 24 записки
первых уровней, 12 — последних, по 3 на сектор. Записка на 20-м этаже — о
страже этажа и о том, где шлюзовая ключ-карта.

### staff, mail, docs, cams, posts, logs, notices

- `staff` — 30–40 записок персонала блока (половина полезных, половина живых).
- `mail` — **массив** переписок, 18–24 (формат одной переписки — как в SPEC.md:
  `{ o, s, m: [[от, тема, текст], …] }`).
- `docs` — **массив** 16–24 документов `{ t, x }`.
- `cams` — **массив** 12–16 записей камер (с маленькой буквы).
- `posts` — **массив** 8–12 должностей.
- `logs` — по 2 строки журнала на каждое своё помещение.
- `notices` — 8 объявлений.

### riddles, rumors, oko

Как в SPEC.md. `oko` — реплики **Переклички** этого блока (не ОКО!): ОКО
не слышит ниже Предела. Те же события: enter, turret_off, turret_hack,
counter, hack_fail, robots, lockdown, alarm, repair, boss, kill, sample,
riddle, taunt — по 3–6 реплик.

### profs, life, view, robotNpc, events — как в SPEC.md

Профессии — люди Нижних этого блока (3–5), `robotNpc` — 1–2.

## 3. Механики глубоких блоков (по мотивам «Низшего», переработанные)

Движок делает их сам; блок даёт им слова.

- **Перекличка.** Разум Нижних: ведёт списки всех, кто внизу, и каждую
  ночь — перекличку. Её глаза — счётчики: сферы на потолочных рельсах (камеры
  движка). Говорит по громкой связи (раздел `oko`), в каждом блоке — своим
  обликом (`deep.ai`): Экзаменатор, Учёный совет, Опытник, Лаборант,
  Перекличка, Главврач, Мастер цеха, Котельщик, Санитарный надзор, Первая.
- **Статус** — ступень в списках: вне списка → низший (испытуемый) →
  допущенный → сменщик → бригадный → старший смены → смотритель. Статус —
  должность, а не сила: он открывает двери с допуском (`rank`), меняет цены
  и товары Нижних, «оружие по допуску», терпение Переклички. Растёт за
  испытания и нормы, падает за преступления.
- **Норма** (`deep.norms`) — задание Переклички на смену:
  `{ id, n: "Норма сборщика", task: "что сделать — одно предложение",
  kind: "parts|kills|samples|repair|visit", need: 5, pay: "в чём оплата — слово" }`.
  Выполнил — оплата и шаг статуса; провалил — норма ниже.
- **Прокат** (`deep.rent`, только блок VI): при входе в блок Перекличка
  выдаёт новичку прокатный комплект — 3–4 модуля `{ id, n, desc, fee }`
  (плата за смену); нечем платить — модули отзывают по одному.
- **Испытание** (`deep.trials`) — стенд в испытательной камере:
  `{ id, n, desc, kind: "survive|find|silent|disarm|chase|puzzle", rank: 1 }`:
  отсчёт от десяти, створки, испытание; прошёл — статус и награда.
- **Вне надзора** (`dark` помещения, `deep.market`): теневой торговец, засады;
  если вернуть надзор с терминала — безопаснее, но торговец уходит.
- **Карточки тварей** (`deep.cards`): при первой встрече Перекличка
  зачитывает карточку — если статус позволяет.
- **Мнемоник** (`deep.memories`): вспышки памяти — звуковые обрывки прошлого
  Нижних; пока длится вспышка, герой беззащитен.
- **Срезы** (`deep.cuts`): короткие пути вниз — на много уровней сразу —
  через тайные комнаты и подсобки. Движок ставит их и считает, на сколько
  уровней уводит срез.

## 4. Смысл обстановки

Каждая вещь в помещении что-то значит — пустых декораций нет:
- `obj` помещения — только то, что в нём логично стоит (в операционной нет
  кровати жильца, в реакторном зале — холодильника; на складе — стеллажи и
  ящики, в кабинете — стол и компьютер). Описание помещения (`desc`) и его
  `obj`, `loot` — об одном и том же месте.
- У каждой вещи — польза или история: компьютер с почтой и журналом,
  терминал с записями, стенд с головоломкой (`puzzle`), верстак, автомат,
  хранилище с находками, запертый шкаф с кодом из записки этого этажа.
- Испытательная камера (`trial: true`) — стенд испытания; помещение «вне
  надзора» (`dark: true`) — без камер, с теневым торговцем; дверь с
  допуском (`rank`) — за ней то, ради чего стоит поднять статус (оружейная,
  архив, хранилище).
- Испытания с `kind: "puzzle"` и срезы с `need: "puzzle"` движок
  открывает головоломкой из общего набора игры (простые, средние, сложные,
  составные и с несколькими верными решениями) — блок пишет только слова.
- Записка с кодом лежит на том же этаже, в другом помещении, и подписана:
  от какой двери код (движок делает сам — не пишите кодов в тексты).

## 5. Правила текстов

Всё из SPEC.md, раздел 3, в силе:
- Ядро Разлома — только на самом дне (блок XV). Выше его не обещать.
- Русский язык, «ёлочки», длинное тире —, буква ё.
- Никогда не называть общее число уровней и этажей, не писать «двадцатый
  этаж», «последний из…», «десятый блок». Номер текущего уровня называть
  можно; размеры блока — нет.
- Не упоминать «Грань Миров» и «Странников»: это последнее слово финала.
- Направления — вперёд, назад, влево, вправо.
- Герой — испытуемый номер семь, «седьмой», носитель «Эхо», мужчина
  тридцати четырёх лет, бывший звукорежиссёр, без зрения. «Эхо» говорит
  голосом Марка Ланского. Без жалости: седьмой слышит больше всех.
- Звук — главное: как место звучит, пахнет, гудит, как отзываются шаги.
- Никаких реальных людей, брендов, политики. Ничего из книг Дема Михайлова
  по имени: ни названий, ни героев, ни цитат — только переосмысленные идеи.
- Без мата, натурализма и жестокости ради жестокости.

## 6. Сюжет глубин

### Что было выше (кратко)

Объект «Ковчег» под горой; реактор «Исток» в Ядре сгибает пространство,
за складкой растёт новый мир — Колыбель. Три недели назад «Исток» вышел на
запредельную мощность, в Ядре открылся Разлом. ОКО — разум «Ковчега»,
садовник, — объявил карантин. Седьмой — носитель «Эхо», в нём ключ.
Сорок лет назад под горой бурили скважину — объект «Глубина» академика
Ростовцева; бур вошёл в «звучащий слой». Первая экспедиция в слой —
**Смена А** — ушла однажды ночью «на звук» и не вернулась. В блоке V
(уровни 81–100) седьмой прошёл лагерь Смены А: перекличка бригадира
Сухова, радиожурнал Лиды Ковригиной, записка пятнадцатилетнего Коли Зотова
(«в списках не значится — здесь, к сожалению»), медицинский журнал Фаины
Берг, лоция геолога Риммы Ольховской. Последний приказ Сухова: «Идём на
звук… Академику — что мы ждём его там, где поют». Ростовцев обещал по
радио: «Ждите, спущусь следом» — и не спустился. На сотом уровне седьмой
остановил «Заглушку» и повернул ключ у пульта настоящего Истока.

### Что ниже Истока

Ключ повернулся — но граница не легла. Исток говорит: Разлом — рана, а не
шов; он прошёл сквозь Исток вниз, сквозь все глубины, и его **ядро — в
самом низу**, под всеми эпохами Нижних. Пока ядро открыто, граница
порвётся. Положить её можно только там, у Ядра Разлома, на самом дне.
Седьмой спускается в Разлом. Это главная цель до конца игры: всё, что
ниже Истока, — путь к ядру; никакой блок не называет себя дном раньше
блока XV, и ни один текст не обещает, что ядро ближе.

Внизу — **Нижние**. Смена А сорок лет назад ушла на звук сквозь Исток, и
там, где время петляет, сорок лет стали веками. Сорок человек выжили,
обжились, родили детей; их потомки за века построили огромный подземный
мир — комплекс за комплексом, эпоха за эпохой, всё дальше от корня, вверх,
к Истоку. Чем глубже — тем старше: спускаясь, седьмой идёт назад по их
истории, от сегодняшнего дня к первому лагерю. И чем глубже — тем дольше
там шло время: поэтому каждый блок вдвое больше прежнего (так говорят и
сами Нижние: «внизу времени было вдвое больше»).

Нижние — научный народ: их мир устроен как один большой институт.
Правит ими **Перекличка** — разум, выросший из радиожурнала Ковригиной,
бурового вычислителя «Глубины» и привычки Сухова считать своих каждый
вечер. Перекличка ведёт списки, раздаёт нормы, статусы и пайки, судит
холодно, по цифрам: «Все здесь?» Тот, кого нет в списках, — никто.
Седьмого в списках нет, как когда-то Коли Зотова. Нижние ждут «того, кто
спустится следом» — Академика; полигон блока VI испытывает каждого, кто
приходит сверху: а вдруг это он?

**Трещина.** Разлом пришёл сверху три недели назад, но в каждой эпохе
Нижних его помнят как «Трещину, что была всегда»: время сложено, и рана
прошла через все века сразу. В каждом блоке — следы Трещины: обвалы,
перекрытые сектора, люди, ушедшие в неё, споры, что это — беда или
обещание.

**Изменённые.** Перекличка карает «переделкой» — нарушителя меняют, и он
становится тварью; одни теряют разум, другие нет. Ещё — опытные твари
лабораторий, дикая фауна глубин, потомки пса Смены А («Пёс пошёл сам»).

**Машины.** Нижние строят машины по чертежам «Глубины» («глубинники»
Ростовцева, буровые автоматы) — в каждой эпохе свои.

**ОКО** ниже Предела не слышит: в глубоких блоках оно молчит; по громкой
связи говорит Перекличка. **Зоя** не дотягивается. **Кварк** ушёл в новый
мир. Но «Эхо» иногда ловит в гуле обрывки голосов сверху.

### Блоки

**VI «Полигон» (испытательный).** Сегодняшний день Нижних, их граница
сверху. Испытательный комплекс: арены, камеры давления и тишины,
огневые полосы, трассы выносливости, смотровые галереи, бронебоксы
затворников-испытателей. Перекличка-Экзаменатор вносит седьмого в списки
низшим, выдаёт прокатный комплект и гонит через испытания: «Испытуемый номер
семь. Опять семь». Испытатели — ранги, скидки, барьерные испытания.
Изменённые — отбракованные испытуемые; машины — экзаменационные стенды,
мишенные дроны, судьи, хронометристы, загонщики, кордоны. Дно блока —
выпускной зал: Экзаменатор объявляет седьмого «не тем» — и всё же пропускает.

**VII «Институт» (исследовательский).** Эпоха великой науки Нижних: они
изучали песню слоя. Обсерватории звука, архивы, кафедры, лектории,
акустические лаборатории, хранилища записей. Учёный совет Переклички.
Скрытый рейтинг поступков, законсервированные проекты, карточки тварей.
Здесь впервые — мнемоник: вспышки памяти первых. Открытие блока:
Нижние вычислили, что Трещина — не беда, а дорога вниз, к корню.

**VIII «Опытный корпус» (экспериментальный).** Эпоха дерзких опытов:
прототипы, опытное оружие, шагоходы, модификационные шлюзы — «переделка»
придумана здесь. Капсулы мутагена у выживших, секции, которые
перетасовываются, гнёзда-коконы. Опытник — самый безжалостный облик.

**IX «Лаборатории» (лабораторный).** Химия и биология Нижних: культуры,
реактивы, ферментеры; биофильтр, что сбежал и зарастает проходы;
каскадные трубы. Здесь вывели многих тварей. Химия героя растёт дальше.

**X «Посёлок» (жилой).** Золотой век: город Нижних — кварталы, рынки,
школы, клубы, мастерские, сады под лампами. Нормы и пайки, вода как
зарплата в нижних кварталах, сумрак без надзора с чёрным рынком, «сутки без
надзора» раз в цикл. Много жителей и заданий. Сама Перекличка — в полный
голос.

**XI «Лечебница» (медицинский).** Больницы, палаты, операционные,
протезные мастерские: тело у Нижних — собственность списков, конечности и
импланты выдают в прокат. Отложенная регенерация, полевая хирургия,
медбокс на двух дронах, кордоны у заразных палат. Главврач Переклички.

**XII «Цеха» (производственный).** Заводы, где Нижние строили свои машины,
пайки, материалы. Где машина сломалась — её работу делали люди: ритм у
вентиля, заслонки, конвейеры. Мастер цеха — облик Переклички, у которого
свои счёты.

**XIII «Котёл» (энергетический).** Тепло Трещины: паровые залы, турбины,
теплообменники, кипящие колодцы. Жар, пар, свист, гул под ногами. Котельщик.

**XIV «Карантин» (карантинный).** Тёмный век: «Тихая» — болезнь, от которой
люди переставали слышать друг друга. Опечатанные кварталы, кордоны,
изоляторы, зоны поглощённого звука — страшнее всего для того, кто слышит.
Санитарный надзор Переклички. Перекличка родилась как ответ на Тихую:
считать вслух, чтобы никто не пропал в тишине.

**XV «Основание» (первый лагерь, корень Разлома).** Самое начало: первые
выработки Смены А, палатки, доска с жетонами, радиорубка Ковригиной,
медпункт Берг, лоции Ольховской, мастерская Глотова, кухня Деева. Первая
перекличка. Записки Коли Зотова, который вырос и стал первым, кто сосчитал
вслух всех. На самом дне — **Ядро Разлома**: трещина, что шла сквозь все
глубины, сходится здесь в тонкую звенящую черту посреди зала, и весь гул
сверху стекается в неё. Последний страж — то, во что превратилась первая
тишина. Дальше — финал (его текст, как и интерлюдию на сотом уровне, пишет
движок, `js/deep.js`; блоки их не пишут).
