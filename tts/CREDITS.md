# Встроенный голос игры

Русская нейросеть говорит прямо на устройстве: без сети (после первой
загрузки модели) и без чужого сервера, одним голосом на любом телефоне.

| Часть | Что это | Лицензия |
|---|---|---|
| `ru_RU-sova200-medium.onnx` | женский голос, Piper (VITS), 22 050 Гц, 63 МБ — встроенный голос по умолчанию. Лежит в папке игры и качается один раз, дальше говорит без сети. Взят из [rraaww/ru_piper](https://huggingface.co/rraaww/ru_piper) (ревизия `f340fe24a52e696bdacbc457d242ac2b0e3bb9ac`) через зеркало [Rotem12/piper-russian-voices](https://github.com/Rotem12/piper-russian-voices/releases/tag/russian-voices-2026-09-15-r2), контрольная сумма сверена с `MODEL_MANIFEST.json` | Apache-2.0 |
| `ru_RU-igm3804-medium.onnx` | мужской голос, Piper (VITS), 22 050 Гц, 63 МБ — выбирается в настройках («Встроенный голос»). Откуда — то же | Apache-2.0 |
| `ru_RU-sova200-medium.onnx.json`, `ru_RU-igm3804-medium.onnx.json` | настройки голосов: частота, таблица звуков (та же, что у разбора игры), темп и паузы | Apache-2.0 |
| `ort/` | [onnxruntime-web](https://github.com/microsoft/onnxruntime) 1.22.0 — движок, который считает модель в браузере | MIT, текст в `ort/LICENSE.txt` |
| `ru-lex.tsv` | звуки и ударения для всех ~25 000 словоформ, что встречаются в текстах игры | собран для игры |
| `ru-stress.json` | ударение по окончанию для слов, которых нет в словаре (выучено на словаре игры) | собран для игры |
| `ru-g2p.js` | разбор незнакомого слова в звуки по правилам русского произношения | написан для игры |
| `grani-tts-worker.js` | рабочий поток: текст → числа словами → звуки → модель → волна | написан для игры |

Ни одной части под GPL: разбор текста свой, без eSpeak. Звуки словаря
записаны в той же нотации, на которой учился голос, поэтому модель слышит
ровно то, что умеет произносить.

Голоса с данными под некоммерческой лицензией (например, `ruslan`) и
голоса с неизвестной лицензией данных (`irina`) нарочно не взяты.

## Как проверено

Голос проверен на настоящей модели через рабочий поток самой игры: модель
встаёт за пять-шесть секунд, первый звук фразы приходит через 0,2–1,3 с.
Разборчивость мерили русским распознавателем речи (GigaAM) на четырнадцати
фразах из игры: 12,4 % ошибок по словам — чуть лучше, чем у того же голоса с
официальным разбором eSpeak (13,1 %). Помогла метка после «ю» (`ʲu"`): на ней
голос учился, и без неё «люк» и «ключ» звучали смазанно.


## Мягкие окончания (версия 3.4)

Словарь записан той же нотацией, на которой учились голоса, а в ней
теряется мягкость согласного на конце слова и перед согласным. Голос
говорил «Гран Миров», «кон», «кроф», «толко». Теперь в словаре (880 слов) и в
разборе незнакомых слов мягкость стоит на месте. Решение принято по
замерам: каждый вариант прочитан обоими встроенными голосами, по 30 слов на
случай, по два дубля, а русский распознаватель GigaAM (без языковой модели:
он слышит сказанное, а не вероятное) показал, какая доля слов узнаётся
точно.

| Случай | Было | Стало |
|---|---|---|
| «нь» на конце («грань», «конь», «камень») | 3 % | 36 % |
| «нь» перед согласным («деньги», «раньше») | 38 % | 57 % |
| «ль» перед согласным («только», «сильный») | 8 % | 39 % |
| «ль» на конце («соль», «цель»), звук `lʲ` | 14 % | 28 % |
| «вь», «фь» на конце («кровь», «верфь») | 25 % | 59 % |
| «зь» на конце («связь», «сквозь»), с оглушением | 25 % | 34 % |
| «пь», «бь» на конце («цепь», «глубь») | 0 % | 14 % |

«Рь» оставлен как был. Мягкое «р» на конце и перед согласным голос
превращает в «й»: «якой» вместо «якорь». Слов узнаётся чуть больше, но
ошибок в буквах тоже больше.


## Ударения сверены (версия 3.6)

Словарь сверен с нейросетью **silero-stress** (Silero, лицензия MIT,
https://github.com/snakers4/silero-stress): она ставит ударение с учётом
смысла фразы и различает омографы. Сверялись все слова озвученных строк
(фразы народов и мест, заставка, женские реплики ремёсел), каждое
расхождение вычитано вручную. Исправлено около ста слов двух родов:

- омографы, где словарь держал редкое значение: «уже́» (было «у́же»),
  «пото́м» (было «по́том»), «моя́», «мою́», «стою́», «стои́шь», «тому́»;
- глаголы и формы, которых не было в словаре, — их ударяло запасное
  правило по окончанию, и неверно: «проси́», «назову́», «повторя́ю»,
  «меня́ю», «сади́сь», «раздува́й», «нале́й», «береги́сь», «прислу́шайся»,
  «плати́», а также «предначе́ртанного», «бревно́», «борода́», «сестра́».

Омографы, у которых оба значения частые и выбор зависит от фразы
(«степи», «рога», «вина», «головы», «стороны», «кости»), в словаре не
тронуты. Сам silero-stress в игру не входит: это инструмент сборки.


## Почему не «Денис»

До этой версии встроенным голосом был Piper «Денис» (данные CC0), и игроки
звали его некачественным. Двадцать русских голосов Piper прочли одни и те же
двадцать фраз игры — лестница, бой, торг, настройки, выбор народа — через
разбор самой игры. Разборчивость слушали два русских распознавателя речи
(Whisper small и GigaAM v2: доля неверно понятых слов, меньше — лучше),
качество звука — DNSMOS P.835 (больше — лучше):

| Голос | Whisper | GigaAM | DNSMOS | Лицензия |
|---|---|---|---|---|
| sova200 (женский) — теперь по умолчанию | 0,25 | 0,08 | 3,23 | Apache-2.0 |
| terra5871 (женский) | 0,28 | 0,10 | 3,24 | Apache-2.0 |
| igm3804 (мужской) — выбирается в настройках | 0,29 | 0,12 | 3,27 | Apache-2.0 |
| luka | 0,29 | 0,08 | 3,25 | Apache-2.0 |
| ruslan (мужской) | 0,33 | 0,12 | 3,23 | CC BY-NC-SA — не взят |
| dmitri (мужской) | 0,34 | 0,12 | 3,23 | CC0 |
| denis (мужской) — прежний | 0,49 | 0,15 | 3,27 | CC0 |
| MMS rus (Meta, VITS, 16 кГц; проверен в версии 3.3) | 0,49 | 0,27 | — | CC BY-NC 4.0 — не взят |

Голоса другого устройства, чем Piper (Silero, Vosk), недоступны из
окружения, где собиралась игра; голоса ElevenLabs — облачные и без сети не
говорят, поэтому встроенным голосом быть не могут.

В версии 3.3 поиск повторён. Русская модель MMS (Meta, `vits-mms-rus` из
выпусков sherpa-onnx на GitHub) распознаётся заметно хуже sova200 и лежит под
некоммерческой лицензией — не взята. Сгенерировать голос в ElevenLabs не вышло:
запас аккаунта исчерпан (0 из 10 000 кредитов). Встроенным остаётся sova200.
