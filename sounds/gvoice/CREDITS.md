# Голос Gemini: постоянные фразы игры

С версии 3.9 игра по умолчанию говорит голосом **Gemini** (Google, модель
`gemini-3.8-flash-tts`, готовый голос **Iapetus**). Постоянные фразы —
пункты меню и настроек, имена окон, частые сообщения — прочитаны заранее, и
каждая лежит здесь отдельной записью: FLAC без потерь, моно, 24 кГц (родная
частота Gemini), 16 бит, громкость −18 LUFS, пик не выше −1 дБ, тишина по
краям срезана, чтобы запись начиналась сразу. То, чего здесь нет (числа,
имена, меняющийся текст), договаривает синтезатор устройства.

Записей: 2987

## Условия

Речь синтезирована по Gemini API. По условиям Gemini API (Gemini API
Additional Terms of Service, https://ai.google.dev/gemini-api/terms) Google не
претендует на права на созданное содержимое; действует Prohibited Use Policy.

## Как сделано

1. Фразы собраны самой игрой: прогон всех наборов проверок записал каждую
   фразу, отданную речи, а обход всех окон — каждый пункт. Взяты предложения
   до пятидесяти знаков без чисел, по частоте.
2. Голос выбран прослушиванием: Kore, Iapetus, Erinome и Achird прочли одни и
   те же тридцать пунктов; все без ошибок распознавания, а модель Gemini в
   роли эксперта по доступности поставила Iapetus выше всех по разборчивости,
   приятности при долгом слушании и верности ударений.
3. Пакеты по 150 фраз; два «говорящих» с одним голосом по очереди, чтобы
   между фразами была пауза. Запись пакета режется по паузам и склеивается
   по распознанному тексту (GigaAM); каждая фраза — не больше 15 % ошибочных
   букв. Не прошедшие в банк не попали: их говорит синтезатор устройства.

Опись для игры — `bank_1.js` (нормализованная фраза → файл). Инструмент —
`tools/voice/gvoice.py`.
