# Клинки, топор, булава, копьё и щиты (версия 4.6)

Удар клинком по телу, по броне и по кости, звон клинка о клинок, укол кинжала,
вход копья, рубка топора, глухой удар булавы, щит, принявший удар, и свой
взмах у каждого рода оружия. Прежний удар меча звучал глухо, как молот.

Все записи сведены в моно FLAC 48 кГц, 16 бит, без потерь. Громкость выровнена по
EBU R128 до −16 LUFS, пик не выше −1 дБ TP. Пересчёт частоты — SoX (soxr,
точность 28 бит). Источники: записи Freesound (48 кГц), исходные WAV 0 A.D.
без сжатия, Kenney RPG Audio (48 кГц). Сведённые файлы названы в описи парой
источников.
