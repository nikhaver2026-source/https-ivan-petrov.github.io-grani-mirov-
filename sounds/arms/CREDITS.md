# Война: рога, столкновения, лязг

Записи в этой папке — настоящие инструменты, а не синтез. Каждый файл —
одна нота одного инструмента, переименованная по игровой роли и подобранная
по регистру: низкие для войны и глубины, средние для мест и народов,
высокие для чар и находок.

Источник: звуковой шрифт **FluidR3_GM** (автор Frank Wen), опубликованный
в виде отдельных нот проектом
[MIDI.js Soundfonts](https://github.com/gleitz/midi-js-soundfonts).
