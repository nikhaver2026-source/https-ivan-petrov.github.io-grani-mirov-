# Голосовой пакет Gemini

Всё, что голос Gemini (Google, модель `gemini-3.8-flash-tts`) прочёл для игры
сверх записей, вшитых в APK и архив для Windows (`sounds/gvoice`,
`sounds/gvoice_f`): им мешает предел GitHub в 2 ГиБ на файл. Обработка та же:
FLAC без потерь, моно, 24 кГц, 16 бит, −18 LUFS, пик не выше −1 дБ, тишина по
краям срезана; годной считается фраза, которую распознаватель речи (GigaAM)
слышит не больше чем с 15 % ошибочных букв. Пакет выходит отдельным файлом
`GraniMirov-voicepack.zip` (выпуск «voicepack-latest»); опись — `m/bank.js`,
`f/bank.js`.

## Условия

Речь синтезирована по Gemini API. По условиям Gemini API (Gemini API
Additional Terms of Service, https://ai.google.dev/gemini-api/terms) Google не
претендует на права на созданное содержимое; действует Prohibited Use Policy.
