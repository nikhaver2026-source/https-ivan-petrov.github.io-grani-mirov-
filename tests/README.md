# Проверки «Грани Миров»

Игра — один файл `index.html` и папка `sounds`. Проверки гоняют её в настоящем
браузере (Chromium через Playwright): нажимают пальцами, слушают речь, читают
состояние мира. Ничего не подменяется заглушками — проверяется та же игра,
которая лежит на GitHub Pages.

## Как запустить

```bash
npm install               # один раз: Playwright
npx playwright install chromium
npm test                  # все наборы
node tests/run.js 20-saves        # только сохранения
node tests/run.js --file          # ещё и по file://, как у игрока с одним файлом
```

Прогон сам поднимает локальный сервер и отдаёт игру **по тому же подпути, что и
GitHub Pages** (`/https-ivan-petrov.github.io-grani-mirov-/`). Это важно: так
проверяются относительные пути и область служебного работника — ровно то, что
ломается при переезде из корня на подпуть.

## Как устроен набор

Каждый файл — самостоятельный скрипт: принимает адрес игры первым доводом,
печатает строки `PASS —` и `FAIL —` и завершается ненулевым кодом при провале.
Прогон (`tests/run.js`) считает строки и сводит итог, поэтому новый набор
достаточно положить в эту папку с именем вида `22-что-проверяем.js`.

Названия проверок пишутся по-русски и по существу: не «test cursor», а
«свайп называет ровно один пункт, а не всё по дороге». По списку провалов
должно быть понятно, что сломалось, без чтения кода.
