# Ворота деревни и решётка из записей игры (пробы)

Слово игрока 12 ноября 2026: «Собери записи из игры и пришли мне пробы» — вместо записей BigSoundBank (№0538, 1539,
1540, 2357, 2360), взятых 11 ноября в обход запрета сайта для роботов.

- `vorota3.py` — сборка проб только из записей, уже лежащих в `sounds/`: OpenClonk (`oc/` — петли, удары по дереву и
  металлу, цепь на вороте), Minetest Game (`mtg/` — крышка сундука, решётчатая дверь), Flare (`deep/` — вагонетка),
  SuperTuxKart (`stk/` — удар молота), Lugaru (`lug/` — лязг), MegaGlest и OpenClonk (`siege/` — взвод камнемёта),
  Stendhal (`hron/` — каменный скрежет), freesound CC0 (`nat/` — деревянная дверь). Обработка и громкость — те же, что
  у остальных ворот (`tools/pipeline/hron/vorota_sborka.py`).
- `vorota3_poisk.py` — перебор вариантов с ярлыками разметчика звуков (целиком и по третям).

Пробы отправлены игроку; в игру (`sounds/vorota/`) записи встанут после его выбора.
