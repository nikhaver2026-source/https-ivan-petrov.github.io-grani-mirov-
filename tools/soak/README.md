# Долгая игра (прогон 16.0) — как продолжить, если прогон сбросился

Здесь харнесс долгой игры «как игрок» и всё, что нужно, чтобы запустить его на новой машине.

| Файл | Что делает |
|---|---|
| `soak8.js` | долгая игра: настоящие клавиши (ходьба, окна, бой, магия, зелья, скакун), пролог в начале, эпизоды по кругу, пробы клавиши, звука, речи и книги, снимок каждые 30 с, ловля зависаний профилировщиком |
| `soak_an.py` | разбор журнала: задержка главного потока, куча после сборки мусора, узлы страницы, интервалы, каналы звука, речь, итог эпизодов |
| `srv8903.js` | сервер игры на порту 8903 (папка репозитория) |
| `run_some.sh` | наборы проверок по очереди против того же сервера |

Эпизоды (по кругу, каждые `EPI` секунд): задание жителя; загадки места (поселения и постройки разных родов); здание;
живое задание с поворотом (дважды за круг); подземелье (вход, спуск, бой, окно яруса); тайна поселения; загадки
в постройках именных городов; чертог; торговля у торговца; загадки яруса; легенда у столицы; загадка яруса Глуби;
сохранение и загрузка.

## Как продолжить на новой машине

```bash
cd /home/user/https-ivan-petrov.github.io-grani-mirov-
git fetch origin claude/gesture-combat-ui-fixes-7tjy3t && git checkout claude/gesture-combat-ui-fixes-7tjy3t
npm install                    # если нет node_modules (нужен playwright; Chromium на машине уже есть)
node tools/soak/srv8903.js &   # сервер игры на 8903
# прогон не меньше полутора часов — 6600 с (110 минут), эпизоды каждые 120 с:
EPI=120 NODE_PATH=$PWD/node_modules node tools/soak/soak8.js http://localhost:8903/index.html 6600 /tmp/soak8_final.log
python3 tools/soak/soak_an.py /tmp/soak8_final.log
```

Если журнал прерванного прогона сохранился и в нём больше 90 минут игры — достаточно разобрать его и догнать остаток;
если журнала нет — прогон целиком заново. Короткая проба отдельных эпизодов:
`EPS="загадкиМеста,тайна,живое" EPI=25 … soak8.js … 150 /tmp/проба.log`.
