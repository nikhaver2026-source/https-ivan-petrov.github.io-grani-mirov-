# Конвейер сборки index.html

`index.html` в корне репозитория — готовая игра, но правят её не в нём. Страница собирается конвейером из частей:

* **основа** — `hron/index_before_mater.html` (около 10 МБ): вся прежняя игра без поздних модулей;
* **ранние и поздние модули** — `hron/mater_early.js`, `mater_hydro.js`, `mater_mod.js`, `mater_hooks.js` и
  `*_late.js`: Великие Материки, престолы, магия Грани, живые города, сюжеты, звук, звери, задания, двери,
  подъёмники, Немота, поиск и тайники, загадки ярусов, Глубь, пролог, свод загадок (`svod155_late.js`), живые
  задания (`zhivye155_late.js`) и другие; порядок задаёт `hron/rebuild.py`;
* **данные модулей** — `voice150_data.json`, `zv_level.json`, `mag_data.py`, `zv_roles.py`;
* **руководство** — `hron/patch_guide_*.py`: каждый скрипт дописывает свои главы в руководство собранной
  страницы (через `guide3/guidelib.py`); их порядок — в `hron/build_all.sh`;
* **правки основы** — `release/release1*.py`: скрипты, которые однажды правили основу (номер версии, новости,
  исправления речи и звука; последний — `release160b.py`, тире и дефис в eSpeak). Они уже применены и лежат здесь
  как история; повторный запуск ничего не меняет.

`FILES.txt` — список файлов, которые сборка действительно читает (снят трассировкой сборки 13 октября 2026 года).
Сборка детерминирована: из этих файлов получается ровно тот `index.html`, что лежит в репозитории.

## Сборка

Пути в скриптах конвейера абсолютные: рабочая папка — `/root/S` (ссылка на временную папку сессии). На новой
машине сначала разложите конвейер по этим путям, потом собирайте:

```bash
bash tools/pipeline/restore.sh            # разложить конвейер (уже лежащие файлы не трогает; --force — перезаписать)
cd /root/S/hron && PHASE=9 bash build_all.sh   # собрать index.html в корне репозитория
```

После сборки — наборы проверок: все (`node tests/run.js`) или нужные (`tools/soak/run_some.sh ЛОГ 322 323 324`
при запущенном `node tools/soak/srv8903.js`).

## Как вносить правки

* Новое поведение — новый поздний модуль `hron/имя_late.js`: впишите его в кортеж модулей в `rebuild.py`
  (перед `konec155_late.js`, он последний) и в `FILES.txt`.
* Правка основы — небольшой скрипт по образцу `release/release155k.py`: находит точный кусок текста, заменяет,
  повторный запуск ничего не меняет.
* Глава руководства — скрипт `patch_guide_*.py` по образцу `patch_guide_svod155.py`, вписанный в `build_all.sh`.
* Номер версии меняется сразу во всех местах (см. `CLAUDE.md`) — образец `release/release160.py`.
* После правок обновите копию конвейера в репозитории: `bash tools/pipeline/sync.sh`, затем закоммитьте.

## Свод загадок — проверки вне браузера

В `svod/` — проверки свода в Node: `svod_node_test.js` (перебор всех загадок, повторы, ответы среди вариантов),
`svod_dups.js` (повторы по механикам), `svod_steps.js` (каждая пошаговая решается своими ходами),
`svod_scan.js` (вычитка текста), `svod_sample.js` (образцы каждой механики), `riddles_new.py` (95 новых
народных загадок с проверкой). Они читают модуль по пути `/root/S/hron/svod155_late.js`.
