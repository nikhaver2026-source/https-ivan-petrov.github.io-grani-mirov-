# Дозапись голосов Gemini (с 4 ноября 2026)

Ежедневная запись фраз интерфейса двумя голосами: мужским **Iapetus** (`sounds/gvoice`) и женским **Callirrhoe**
(`sounds/gvoice_f`), модель `gemini-3.8-flash-tts`. Рабочая папка — `/root/S/gvrec` (`/root/S` — ссылка на
scratchpad сессии); скрипты отсюда копируются туда. Ключей здесь нет и не должно быть: их кладёт в
`/root/S/keys/.gemini_key*` загрузчик вне репозитория (из переменной среды `GEMINI_API_KEYS` или запасных копий).

| Файл | Что делает |
|---|---|
| `srv8907.js` | сервер игры для сбора фраз: как `tools/soak/srv8903.js`, но в страницу вставлен собиратель — всё, что отдано речи (`Speech.say`, даже подменённое набором), и подписи `data-speak` уходят в `collect.txt` |
| `capfail.sh` | дособрать фразы с наборов, упавших при сборе (список — `cap_fail.txt`) |
| `gvqueue.py` | очередь записи из `collect.txt`: текст режется, как в игре (`Speech.gvParts`) — целиком, предложения, части по «:» «;» и тире; в очередь — куски, которых нет ни в описи голоса, ни в голосовом пакете (`sounds/gvoice_pack`), без цифр и латиницы, 2–90 знаков; частые впереди; `не_просить.json` — прежние отказы |
| `gvrec2.py ГОЛОС N [ОЧЕРЕДЬ]` | один запрос — сырой пакет из N фраз (`raw/<m|f>/packNNN.wav` + `.json`); ключи по очереди, исчерпанный — следующий; сутки ключа — от 07:00 до 07:00 UTC |
| `gvcut.py ГОЛОС` | нарезка (Python 3.13, `sherpa-onnx`, модель `sherpa-onnx-nemo-ctc-giga-am-v2-russian-2025-04-19` в `/root/S/asr`): дробление по паузам от 0,1 с, распознавание кусков, сборка фраз динамическим программированием по доле ошибочных букв; годная фраза — не больше 12 % ошибочных букв и не медленнее 8 знаков в секунду; края 30/60 мс; −18 LUFS, пик не выше −1 дБ; FLAC 24 кГц моно 16 бит |
| `gvapply.py` | встроить нарезанное ровно один раз (метка `cut/встроено.json`): файлы — следующими номерами, опись — на следующий номер (`git mv bank_N → bank_N+1`), счёт в CREDITS, ссылка в основе конвейера |
| `ci2.py` | сверка: каждая запись описи на диске, каждый файл задействован, игра подключает последнюю опись |
| `d_run.sh ЧИСЛО` | день: очередь → пакеты m/f попеременно до конца квоты → нарезка; журнал `d<ЧИСЛО>.log` |
| `apply.sh ЧИСЛО` | встроить, собрать конвейером (`hron/build_all.sh`), сверить, обновить копию конвейера, убрать день в архив |

Порядок дня: `capfail.sh` или полный сбор (по желанию, через `srv8907.js` и `runlist` с портом 8907) →
`d_run.sh ЧИСЛО` → после «ГОТОВО» — `apply.sh ЧИСЛО` → наборы голосов (36, 67, 119, 177, 190, 191, 193, 194, 213,
214, 218, 219, 221, 226, 227, 253, 257, 266, 285, 299–306) → коммит. Наборы браузера не гонять одновременно с
записью.
