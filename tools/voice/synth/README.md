# Синтезатор-склейка голосом Gemini (новый движок, с 4 ноября 2026)

В игру пока НЕ встраивается — доводится до идеала. Рабочая папка — `/root/S/us2` (scratchpad сессии); здесь копия кода.
Разбор недостатков и что сделано — `АНАЛИЗ.md`.

| Файл | Что делает |
|---|---|
| `db_build.py ГОЛОС [pack]` | база слов: каждая запись голоса (и голосового пакета) распознаётся GigaAM; в базу — записи с точным совпадением слов; время каждой буквы |
| `fix_bounds2.py ГОЛОС [_pack]` | границы слов по переходу звука (не по тишине: тишина внутри глухого «с» срезала начало слова) |
| `punct.py` | исходные тексты записей со знаками препинания (интонация конца) |
| `occ_check.py ГОЛОС` | чистота вхождений: слово вырезается и распознаётся отдельно (возобновляемо) |
| `engine.py` | движок: текст (числа, латиница, отрезки), выбор Витерби (цепочки слов, слова, части слов с учётом ударения — словарь Koziev/NLP_Datasets all_accents, CC0), знаки, мелодия фразы, края без чужих хвостов, сглаживание высоты, стыки по волне, темп WSOLA |
| `eval.py ГОЛОС N МЕТКА [веса]` | проверка на настоящих незаписанных фразах игры: доля ошибочных букв и слов по распознавателю, скачки высоты на стыках, пробы |
| `judge.py МЕТКА [модель]` | судья-слушатель Gemini: естественность и разборчивость 1–10, беды по словам |

Нужны: Python 3.13 с `numpy`, `soundfile`, `sherpa-onnx`; модель `sherpa-onnx-nemo-ctc-giga-am-v2-russian-2025-04-19` в `/root/S/asr`;
словарь ударений `/root/S/us2/dict/stress.json` (из `all_accents.tsv`).
