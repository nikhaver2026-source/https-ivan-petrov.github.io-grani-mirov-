# Синтезатор-склейка голосом Gemini (новый движок, с 4 ноября 2026)

В игру пока НЕ встраивается — доводится до идеала. Рабочая папка — `/root/S/us2` (scratchpad сессии); здесь копия кода.
Разбор недостатков и что сделано — `АНАЛИЗ.md`.

| Файл | Что делает |
|---|---|
| `db_build.py ГОЛОС [pack]` | база слов: каждая запись голоса (и голосового пакета) распознаётся GigaAM; в базу — записи с точным совпадением слов; время каждой буквы |
| `fix_bounds2.py ГОЛОС [_pack]` | границы слов по переходу звука (не по тишине: тишина внутри глухого «с» срезала начало слова) |
| `punct.py` | исходные тексты записей со знаками препинания (интонация конца) |
| `occ_check.py ГОЛОС` | чистота вхождений: слово вырезается и распознаётся отдельно (возобновляемо) |
| `engine.py` | движок: текст (числа, латиница, отрезки), выбор Витерби (цепочки слов, слова, части слов с учётом ударения — словарь Koziev/NLP_Datasets all_accents, CC0), знаки, мелодия фразы, края без чужих хвостов, сглаживание высоты, стыки по волне, темп WSOLA |
| `eval.py ГОЛОС N МЕТКА [веса]` | проверка на настоящих незаписанных фразах игры: доля ошибочных букв и слов по распознавателю, скачки высоты на стыках, пробы |
| `judge.py МЕТКА [модель]` | судья-слушатель Gemini: естественность и разборчивость 1–10, беды по словам |
| `fon.py` | произношение фразы: поверх `g2p.py` — тся → [ца], что → [што], -ого → [ава], сч → [щ], непроизносимые согласные, уподобление по звонкости на стыках слов, «ё» по текстам игры (`yo_words.json`) |
| `hmm_align.py ГОЛОС [проходов]` | свой разметчик звуков: скрытая марковская модель (48 звуков × 3 состояния, смеси до 8 гауссиан, шаг 5 мс), обучение Витерби на всех записях; итог — `hmm_<голос>.npz` и `align_<голос>.jsonl` (нужен `numba`) |
| `align_apply.py ГОЛОС` | разметку — в базу: края слов по звукам, звуки слова «ph» с временем |
| `align_new.py ГОЛОС ФАЙЛ...` | разметить обученной моделью новые записи базы (корпус, свежие записи) |
| `align_eval.py [N]` | проверка разметки: слова, вырезанные прежним способом и по разметке, распознаются поодиночке |
| `diag.py ГОЛОС a:b МЕТКА` | разбор ошибок по словам: лишние буквы на стыках, проглоченные окончания, по видам единиц (цепочка, слово, части) |
| `pieces.py "фраза"` | куски синтеза по отдельности: источник, границы, что слышно в каждом куске и паре кусков |
| `phone_index.py ГОЛОС` | указатель всех звуков базы (711 тыс.) с признаками середины звука — для сборки незнакомых слов из всей речи диктора (`поток=1`, пока выключено: в среднем не лучше дифонов внутри слов) |
| `dbupd05.sh` | пополнение базы новыми записями: `db_build.py m add`, разметка `align_new.py`, признаки, `occ_check.py m inc` (чистота — по ключу «файл#слово» в `occ_m_map.json`) |
| `psola.py` | сдвиг высоты по периодам основного тона (TD-PSOLA) без изменения тембра и длительности; плавные переходы высоты на стыках |
| `join_learn.py ГОЛОС` | выученная цена шва по живой речи диктора (перепад спектра, громкости и высоты на настоящих границах слов, по парам видов звука) → `join_<голос>.json` |
| `learn_data.py N SEED`, `learn_fit.py ФАЙЛЫ` | обучение цен выбора по исходам распознавания (логистическая регрессия) |

Нужны: Python 3.13 с `numpy`, `soundfile`, `sherpa-onnx`; модель `sherpa-onnx-nemo-ctc-giga-am-v2-russian-2025-04-19` в `/root/S/asr`;
словарь ударений `/root/S/us2/dict/stress.json` (из `all_accents.tsv`).

Честная проверка: `eval.py` и `diag.py` задают `SYNTH_EXCLUDE` — записи, совпадающие с проверочными фразами (или их
частью от трёх слов), в выборе не участвуют. Наборы: `test_set.json` (155 фраз), `test_set400.json` (400 фраз; `EVAL_SET=…`).
