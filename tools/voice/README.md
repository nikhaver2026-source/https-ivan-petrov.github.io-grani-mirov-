# Голоса народов: как записать оставшиеся

Сто двенадцать народов мира откликаются своим голосом. Тридцать семь реплик
народов лежат в `sounds/voice/race_*.mp3`; тексты всех тридцати семи собраны
здесь, в `lines.json`, а подобранные голоса ElevenLabs — в `voices.tsv`.

**Что уже сделано.** Три записи — `race_gnomy`, `race_orki`, `race_ogry` —
переписаны новыми дублями и подогнаны под основную частоту своего народа
(89,4 / 82,1 / 91,4 Гц при цели 89,6 / 82,1 / 91,2). Остальные тридцать
четыре — дубли прежнего поколения, 162 кбит/с, без подгонки: их ждёт
переработка, как только вернётся месячная квота ElevenLabs. Поимённо они
перечислены в `sounds/voice/CREDITS.md` строкой «текст готов, запись ждёт
квоты».

## Как переписать одну реплику

1. Взять текст и голос:

   ```sh
   python3 -c "import json,io;d=json.load(io.open('tools/voice/lines.json',encoding='utf-8'));print(d['race_trolli'])"
   grep '^race_trolli' tools/voice/voices.tsv
   ```

2. Сотворить дубль в ElevenLabs этим голосом и этим текстом, скачать mp3.

3. Подогнать дубль под голос народа — под тот, что уже звучит в игре:

   ```sh
   python3 tools/voice/voicefit.py сырая.mp3 sounds/voice/race_trolli.mp3 новая.mp3
   ```

   Высота не «сдвигается на столько-то», а **приводится** к той, что у народа
   уже есть: у каждого дубля своя основная частота, и постоянный сдвиг увёл бы
   народ от собственного голоса. Форманты сохраняются — меняется голос, а не
   скорость речи. Подгонка идёт по несжатому промежуточному файлу и уточняется
   до трёх раз (растяжитель не даёт ровно тот множитель, о котором его просят),
   а в mp3 запись переводится ОДИН раз, в самом конце: потерь одно поколение,
   а не три.

4. Сверить, что получилось:

   ```sh
   python3 tools/voice/f0.py sounds/voice/race_trolli.mp3 новая.mp3
   ```

   Расхождение до полутора процентов слухом не ловится; больше — гнать ещё раз.

5. Положить на место, поправить строку в `sounds/voice/CREDITS.md` и строку
   файла в `sounds/BITRATE_BASELINE.txt`, если битрейт изменился.

## Почему 192, а не 320

Тариф ElevenLabs Creative отдаёт mp3 не выше 192 кбит/с. Пережимать его в 320
бессмысленно: пережатие не возвращает того, чего в файле нет, а вес поднимает
втрое. Поэтому записи голосов остаются в 192 и записаны в
`sounds/BITRATE_BASELINE.txt` поимённо — правило «320 всему новому» стережёт
набор 152, и эти строки для него исключение с объяснением.

## f0.py

Медианная основная частота речи по озвонченным кадрам: автокорреляция, окно
40 мс, шаг 10 мс, порог громкости и порог уверенности. Нужна и для подгонки,
и для проверки. Зовётся сама по себе:

```sh
python3 tools/voice/f0.py sounds/voice/race_gnomy.mp3
```
